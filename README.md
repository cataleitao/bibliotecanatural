# Natural Library | Biblioteca Natural

Site estático de bibliotecanatural.catarinaleitao.net, publicado pelo GitHub Pages.

- `_fonte/conteudo.json` — textos, legendas e listas de imagens (início, catálogo, itinerância). É aqui que se edita.
- `_fonte/gerar.py` — gera as páginas e as imagens: `python3 _fonte/gerar.py <pasta dos originais>`.
- `_fonte/ao.py` — conversão para o Acordo Ortográfico de 1990 nas partes em português.
- As pastas que começam por `_` não são publicadas.
